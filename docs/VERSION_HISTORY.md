# Version history

- **V1 Basic** — ESP32, LED, code editor, Serial Monitor, mini interpreter.
- **V2 Interactive Wiring** — nối GPIO/GND vào breadboard, Circuit Doctor.
- **V3 Sensors** — DHT22, HC-SR04, OLED, Logic Analyzer, môi trường mô phỏng.
- **V4 Breadboard Netlist** — node breadboard, R/C/LED/potentiometer, RC/ADC/oscilloscope.
- **V5 MNA Solver** — Modified Nodal Analysis prototype, R/C/L/diode/LED, Newton iteration, probes.
- **3D Three.js Prototype** — thử scene WebGL/Three.js, phụ thuộc CDN.
- **3D Offline Prototype** — thử renderer tự chứa để tránh CDN/WebGL dependency issues.
- **Visual Prototype 1** — thử CSS 3D/SVG, xác nhận chất lượng vẫn thấp hơn nhiều so với mục tiêu tham chiếu.
